# Mental_Health_Score_Predictor
Using Ml


Problem:
I'm going to predicting a students mental health score using their social media habits,study time,sleep,physical activity,and stress level. This is a regression problem since the target is a number , not a category


Dataset:
Student_Social_Media_And_Mental_Health_Impact.csv
5000 students,13 columns (Age,gender,country) platform usage(Daily_Usage_hours,Daily_unlocks,most_Used_platform), lifestyle (Study_Hours,Sleep_Hours_Per_Night,Physical_Activity_Hours) and Stress_Level
